Weather App

User Operations Guide

Understanding interactive variables, geolocation hooks, and system gestures.

01

Auto-Location Sync

Upon initial page load, the browser triggers an HTML5 GPS query. Selecting 'Allow' extracts geographic coordinates (Latitude & Longitude), center-pans Leaflet maps, and syncs weather details instantly.

02

Search & Dropdowns

Clicking inside the location input field displays a "Recent Searches" history dropdown. Pressing 'Enter' or clicking results queries the backend, appending queries to history parameters stored in LocalStorage.

03

Radar Map Overlays

The integrated dark Leaflet satellite map serves real-time layer overlays (Atmospheric clouds/precipitation) pulled directly from OpenWeatherMap tile clusters using dynamic keys passed from backend routes.

04

VFX Overlays Sync

The system automatically switches visual looping backdrops (rain, moving clouds, snow, or mist) and coordinates Three.js particle velocities, fog limits, and lighting profiles to reflect local weather reports.
